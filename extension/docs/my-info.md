# my-info: 내 정보 창 개선 (김도형)

사용자 결정(2026-11-26)으로 내 정보 창을 고쳤다.

## 바뀐 것

1. **전역·예비군(B 그룹)**: 지원 분야 선택과 나의 지원 D-Day를 보여 주지 않는다. 제목은 `내 정보`, 내용은 로그인 칸·인적사항·화면 설정.
2. **지원 희망 분야 고르기**: 직접 입력하지 않고 군(육군/해군/해병대/공군) → 모집 구분(일반병/전문기술병/전문특기병) → 특기(또는 계열) 순으로 고른다.
   - 육군은 병무청 표기대로 전문기술병 자리에 `기술행정병`을 둔다. 기술행정병은 군사특기를 골라 지원하므로 147개 특기에서 고른다.
   - 해군·해병대·공군 기술병은 계열을 골라 지원하고 실제 특기는 입영 뒤에 나눈다. 그래서 3단계 이름을 `계열`로 보여 준다.
   - 목록이 20개보다 많으면(육군 기술행정병·전문특기병) 버튼을 늘어놓지 않고 검색칸으로 줄여서 고른다.
   - 일반병은 2단계에서 바로 저장.
   - D-Day는 특기 이름으로 먼저 찾고, 없으면 모집 구분으로 찾는다(이달의 모집계획에서 기술행정병은 한 줄이라 기술행정병 일정이 보인다). 다른 군 이름만 적힌 일정은 뺀다(`match.ts`).
   - 예전에 직접 입력해 저장한 분야(`{ role }`만 있음)는 예전 방식대로 검색한다.
3. **지원 분야 변경 버튼**: 12px 글자 링크 두 개를 16px 큰 버튼 두 줄로 바꿈(지원 분야 변경은 채운 버튼).
4. **로그인 남은 시간**: 병무민원 탭이 원본 `#counter`와 나가기/로그인 버튼을 1초마다 읽어, 로그인 상태와 만료 시각만 `bmgj.portalLogin.v1`에 저장한다.
   로그인 중이면 내 정보의 `병무청 공식 로그인` 칸 대신 남은 시간을 보여 준다(5분 미만이면 주황색과 연장 안내). 병무청 누리집 탭에서도 같은 값을 읽는다.
   로그아웃은 원본 위쪽 링크(`#util_layout2`)에 `로그인` 또는 `접속하기`가 보일 때만 알아챈다(화면을 옮기는 순간에 버튼을 못 읽는 경우를 로그아웃으로 보지 않기 위해).
   로그아웃 상태의 원본 링크는 `접속하기`라서 `readSession().canLogin`(`로그인` 글자만 찾음)으로는 알 수 없어 `portalLogin.ts`에서 따로 본다.
5. **인적사항 항목**: 통합지원서 '기본정보' 화면에 맞춘 칸만 저장한다(저장 키 `bmgj.personalProfile.v2`).
   - 연락처: 전화번호(비상연락처)·휴대전화·전자우편(상용)·응시지역 병무청(통합지원서 select 14곳과 같은 목록).
   - 학력사항: 통합지원서처럼 학교 구분(초등학교·중학교·고등학교·대학교·대학원·직업전문/인력개발원)마다 한 줄.
     칸은 학교명·전공학과·학제(대학교·대학원)·학위(대학원)·학년·졸업구분, 직업전문은 수료기간. 학교 구분마다 고를 수 있는 학년·졸업구분이 다르다(`options.ts`의 `LEVEL_SPECS`).
   - 자격/면허: 명칭·취득시기(최대 10개). 통합지원서에 없는 등급·자격 번호·발급 기관 칸은 뺐다.
   - 신체조건사항: 신장·체중·시력(좌/우)·색각. 통합지원서 기본정보 화면에는 없어서 내 정보에만 적어 둔다.
   - 나라사랑메일·성명·생년월일·병적지청·주소·계좌는 저장하지 않는다. v1 값은 읽을 때 쓰는 칸만 옮기고, 저장하거나 가져올 때 v1 키를 지운다.
   - 첫 v2 형식(학교 구분 `대학교(4년제)`, 학년 `1`, 입학/졸업 연월)은 읽을 때 새 칸으로 옮긴다.
6. **통합지원서 ↔ 내 정보 버튼**(`profileSync.ts`): 예전처럼 통합지원서를 열자마자 자동으로 읽지 않는다.
   통합지원서 기본정보 화면의 인적사항 표 위에 `병무길잡이 · 내 정보 연결` 박스를 붙이고, 버튼을 누른 뒤 박스 안에서 `예`를 눌러야 움직인다.
   - **내 정보로 채우기**: 내 정보 값을 지원서 입력칸에 넣는다(값이 있어도 덮어씀). 전화번호는 원본 안내대로 숫자만 넣는다.
     학력은 고르기 칸(학제·학위·학년·졸업구분·수료기간, 직업전문 학교)만, 자격/면허는 지원서에 같은 명칭이 있는 줄의 취득시기만 넣는다.
     학교명·전공학과·자격/면허 명칭은 원본 검색 팝업이 숨은 코드값을 같이 넣는 읽기 전용 칸이라 채우지 않고 안내만 한다.
     값이 이미 같으면 손대지 않는다(원본이 change 이벤트로 자격/면허 줄을 '수정됨'으로 표시하는 것을 막기 위해).
     저장·다음·제출 버튼은 누르지 않는다.
   - **내 정보에 가져오기**: 지원서에 보이는 연락처·학력·자격/면허를 내 정보에 저장한다(학력·자격/면허는 지원서 내용으로 바뀜, 신체조건은 그대로).
   - 성명·생년월일은 그 표가 본인 표인지 확인하고, 다른 사람이 로그인했는지 가리는 SHA-256 해시로만 쓴다(원문은 저장 안 함).
     내 정보가 다른 사람의 것이면 채우지 않고, 가져올 때는 이전 사람의 값을 이어 쓰지 않는다.
   - 원본 칸 이름이 `전화번호(비상연락처)`라 예전 자동 반영은 전화번호를 읽지 못하던 문제도 고쳤다.

## 확인한 것 (2026-11-26, Chrome에 압축해제 로드)

- (a) 전역·예비군: 지원 분야·D-Day가 사라지고 제목이 `내 정보`.
- (b) 육군 → 기술행정병 → 검색 `조리` → 저장, D-Day 표시.
- (c) 지원 분야 변경·일정 새로고침 버튼 두 줄.
- (d) 병무민원 로그인 뒤 병무청 누리집 탭에도 남은 시간 표시, 병무민원에서 `연장`을 누르면 두 탭 모두 갱신, `나가기`로 로그아웃하면 다시 `병무청 공식 로그인` 칸.
- (e) 가짜 값으로 인적사항 입력·저장·수정·삭제, 응시지역 드롭다운, 학교 구분별 칸 바뀜.
- (f) 통합지원서에서 가져오기(연락처 3칸·학력 4줄·자격/면허 4개) → 같은 값 채우기: 숨은 칸을 포함한 입력값 185칸이 하나도 바뀌지 않음.
- 콘솔: 확장 프로그램을 새로고침하기 전에 열려 있던 탭의 `Extension context invalidated`만 보였다(탭을 새로고침하면 없어짐).
  `[bmgj] DOM not found`(www.mma.go.kr/)는 지금 병무청 첫 화면 자리에 본인선택원 신청 안내 페이지가 떠 있어서 `findOriginalDom()`이 원래 첫 화면을 못 찾는 것. 이번 변경과 관계없고, 공용 파일(`src/content/main.tsx`)이라 고치지 않았다.

## 확인 필요

- 같은 원인(`접속하기`)으로 로그아웃 뒤 병무민원 새 화면 위쪽에 로그인 버튼이 보이지 않는다. `src/portal/portalDom.ts`의 `utilElements()`에서 `접속하기`도 로그인 링크로 보면 고쳐진다(공용 파일이라 이번에는 고치지 않음).

- 특기 목록 출처는 `roles.ts` 각 목록 위 주석. 첨부파일(군사특기별 모집인원)은 문서뷰어에서 그림으로만 열려 이름 대조는 공고 본문과 안내 페이지로 했다.
  해군·해병대·공군 전문특기병은 회차마다 바뀌어 최근 두 회차(26-11·26-12)를 합쳤다.
- 신체조건 칸은 통합지원서에서 모집분야를 고른 뒤 단계에 있는지 확인하지 못했다(`다음`을 눌러야 해서).
- 병무청 ↔ 병무민원을 같은 탭으로 옮기는 변경은 팀 규칙에 따라 이번 작업에서 뺐다.
