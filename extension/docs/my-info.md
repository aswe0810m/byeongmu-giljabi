# my-info: 내 정보 창 개선 (김도형)

사용자 결정(2026-11-26)으로 내 정보 창을 고쳤다.

## 바뀐 것

1. **전역·예비군(B 그룹)**: 지원 분야 선택과 나의 지원 D-Day를 보여 주지 않는다. 제목은 `내 정보`, 내용은 로그인 칸·인적사항·화면 설정.
2. **지원 희망 분야 고르기**: 직접 입력하지 않고 군(육군/해군/해병대/공군) → 모집 구분(일반병/전문기술병/전문특기병) → 특기 순으로 고른다.
   육군은 병무청 표기대로 전문기술병 자리에 `기술행정병`을 둔다. 특기 목록이 없는 구분(일반병, 육군 기술행정병)은 2단계에서 바로 저장.
   D-Day는 특기 이름으로 먼저 찾고, 없으면 모집 구분으로 찾는다. 다른 군 이름만 적힌 일정은 뺀다(`match.ts`).
   예전에 직접 입력해 저장한 분야(`{ role }`만 있음)는 예전 방식대로 검색한다.
3. **지원 분야 변경 버튼**: 12px 글자 링크 두 개를 16px 큰 버튼 두 줄로 바꿈(지원 분야 변경은 채운 버튼).
4. **로그인 남은 시간**: 병무민원 탭이 원본 `#counter`와 나가기/로그인 버튼을 1초마다 읽어, 로그인 상태와 만료 시각만 `bmgj.portalLogin.v1`에 저장한다.
   로그인 중이면 내 정보의 `병무청 공식 로그인` 칸 대신 남은 시간을 보여 준다(5분 미만이면 주황색과 연장 안내). 병무청 누리집 탭에서도 같은 값을 읽는다.
   로그아웃은 원본 화면에 로그인 버튼이 보일 때만 알아챈다(화면을 옮기는 순간에 버튼을 못 읽는 경우를 로그아웃으로 보지 않기 위해).
5. **인적사항 항목**: 전화번호·휴대전화·전자우편·응시지역 병무청·학력사항·자격증·신체조건사항만 저장한다(저장 키 `bmgj.personalProfile.v2`).
   - 나라사랑메일·비상연락처·성명·생년월일·병적지청·주소는 저장하지 않는다. v1 값은 읽을 때 쓰는 칸만 옮기고, 저장하거나 자동 반영할 때 v1 키를 지운다.
   - 응시지역 병무청은 목록에서 고른다(지방청 안내 페이지의 지방병무청 11곳 + 병무지청 3곳).
   - 학력사항(학교 구분·학교명·학과·학년·학적 상태·입학/졸업 연월)은 최대 4줄, 자격증(자격·면허명·등급·취득일·자격 번호·발급 기관)은 최대 10줄.
   - 신체조건사항: 신장·체중·시력(좌/우)·색각.
   - 통합지원서 자동 반영은 전화번호·휴대전화·전자우편·응시지역만 읽는다. 성명·생년월일은 그 표가 본인 표인지 확인하고, 다른 사람이 로그인했는지 가리는 SHA-256 해시로만 쓴다(원문은 저장 안 함).

## 확인 필요

- 특기 목록(`roles.ts`)은 2026-11-26 병무청 공개 페이지에서 읽은 것. 해군·해병대·공군은 공고 본문 일부라서 첨부파일(정본)과 다를 수 있다. 육군·공군의 `어학병`은 전문특기병 안에 넣었다.
- 학력·자격증·신체조건 칸(`options.ts`, `profile.ts`)은 실제 통합지원서 화면(로그인 필요)과 맞춰 보지 못했다. 다르면 이 두 파일만 고치면 된다.
- 병무청 ↔ 병무민원을 같은 탭으로 옮기는 변경은 팀 규칙에 따라 이번 작업에서 뺐다.
