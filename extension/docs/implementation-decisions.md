# 구현 결정 기록

명세서 v3.0에 없거나 애매해서 직접 정한 것. 형식: 무엇을 — 왜.

## 1단계
- manifest에 `"version": "0.1.0"` 추가 — Chrome은 version 없는 manifest를 로드하지 않음(명세 9절은 "핵심"만 보여 줌).
- 빌드 결과는 `extension/dist/`(content.js + manifest.json), Chrome에서는 이 폴더를 로드 — 소스와 빌드 결과를 분리하기 위해.
- Vite 라이브러리 모드로 IIFE 단일 파일 `content.js` 생성 — MV3 콘텐츠 스크립트는 ES 모듈 import를 쓸 수 없음.
- manifest.json은 vite.config.ts 안의 작은 인라인 플러그인으로 dist에 복사 — 복사용 라이브러리를 추가하지 않기 위해.
- `@vitejs/plugin-react`를 쓰지 않고 Vite 내장 esbuild의 `jsx: 'automatic'`으로 TSX 처리 — 명세 9절에 없는 패키지를 늘리지 않기 위해.
- 의존성 버전 고정(react 18.3.1, react-dom 18.3.1, lucide-react 0.460.0, vite 6.4.5, typescript 5.9.3, @types/react 18.3.31, @types/react-dom 18.3.7) — 재현 가능한 빌드를 위해.
- tsconfig `include`는 `src`만 — vite.config.ts까지 넣으면 `@types/node`가 추가로 필요해짐.
- 단일 링크 카드의 `MenuLink.label`은 카드 이름과 같게 둠 — 4절 표에 단일 링크의 별도 이름이 없음.
- 강조 카드는 `tone: 'solid'`로 표시하고 별도 필드를 두지 않음 — 4절 표에서 강조 카드(A-M06, B-M01)만 "채움"이고, 명세의 HomeCard 형식을 바꾸지 않기 위해.
- `cards.ts`에는 표의 상대 경로를 그대로 적고, 내보낼 때 `https://www.mma.go.kr`을 붙인 `cards`를 제공 — 표와 대조하기 쉽고, 화면은 항상 절대 주소만 받게 하기 위해.
- 검사에 "카드 ID 중복 없음", "카드마다 링크 1개 이상" 추가 — 렌더링이 이 두 가지를 전제로 하므로.
- 1단계의 `main.tsx`는 메뉴 데이터 검사만 수행(실패 시 콘솔 오류) — 빌드 진입점이 필요하고, 적용 조건·숨김은 2단계 범위.

## 2단계
- 개발용 타입 `@types/chrome` 0.1.43 추가(devDependencies만) — chrome.storage 타입 확인용, 사용자 허락받음. 빌드 결과에는 포함되지 않음.
- `src/vite-env.d.ts` 추가 — `styles.css?inline`을 문자열로 가져와 Shadow DOM `<style>`에 넣기 위한 타입 선언.
- 루트 컴포넌트 `src/ui/App.tsx` 추가 — 명세 9절 ui 목록에 없지만 화면 모드 상태와 구성 요소를 묶을 곳이 필요함.
- 원본 숨김은 `display: none !important` 인라인 스타일로 함 — 원본 CSS가 `hidden` 속성을 덮어쓸 수 있으므로. 원래 `style` 속성(없으면 없음)과 `hidden` 값을 기록해 그대로 복원.
- 저장값을 먼저 읽은 뒤 숨김을 적용 — 원본 모드 사용자에게 숨겼다가 다시 보여주는 깜빡임을 막기 위해(개선 모드에서는 읽는 동안 원본이 잠깐 보일 수 있음).
- "확장 루트를 숨긴다"(3.8)는 루트 요소는 남기고 그 안에 개선 화면 대신 `병무길잡이 켜기` 버튼만 그리는 것으로 구현 — 켜기 버튼을 둘 별도 요소를 페이지에 만들지 않기 위해. 루트 자체는 높이 0이라 원본 화면에 영향 없음.
- Shadow DOM은 `mode: 'open'` — 확장을 다시 불러와 스크립트가 재실행될 때 기존 루트 내용을 비우고 다시 그리기 위해.
- 전환 후 포커스: `원래 화면 보기` → `병무길잡이 켜기` 버튼, 켜기 → `원래 화면 보기` 버튼 — 누른 버튼이 사라져 포커스를 잃지 않게.
- `병무길잡이 켜기` 버튼은 글자만(아이콘 없음) — 3.8은 "내 정보 버튼과 같은 모양·위치"만 정함.
- 2단계 개선 화면에는 `원래 화면 보기` 버튼만 둠(임시) — 완료 기준 확인용. 3단계에서 헤더의 같은 버튼으로 옮김.
- 콘솔 메시지는 `console.error`로 남김 — 7절은 "콘솔에"만 정함.
- 원본 `#krds-header`의 `margin-bottom: 12px` 틈으로 body 배경(파란 gif)이 보이고, 개선 화면 아래는 body의 흰 배경이 보이는 것은 그대로 둠 — 명세 2절의 숨김 대상 3곳 밖은 건드리지 않기로 사용자가 결정((나) 선택).

## 3단계
- 그룹 표시 이름(`입영 준비·복무 중`/`전역·예비군`)은 `cards.ts`의 `GROUP_LABELS` 한 곳에 둠 — 선택창·select·배지가 같은 문구를 쓰므로. ID로 카드를 찾는 `getCard()`도 추가(배너 버튼 링크용).
- 모달 키보드 처리(포커스 가두기·Escape)는 `src/ui/useModal.ts`로 분리 — 3.6 내 정보 대화상자에서도 같은 동작을 쓰기 위해.
- 선택창이 열릴 때 포커스는 대화상자 자체에 둠 — A/B 버튼에 두면 포커스 테두리 때문에 "선택된 것처럼" 보이므로(3.1 "처음에 어느 버튼도 선택된 것처럼 보이지 않는다").
- 선택창 뒤의 틀은 헤더(그룹 select 없음) + 문구 없는 빈 배너 상자 — 3.1 "카드 없이"만 정해져 있고 그룹이 없으면 배너 문구를 고를 수 없음. 선택창이 열린 동안 틀에는 `inert`를 걸어 조작 불가.
- 선택창의 `원래 화면으로 보기`는 이동이 아니라 동작이므로 링크 모양의 `<button>`으로 만듦 — 8절 "링크/버튼을 섞지 않음"과 의미상 맞추기 위해.
- 첫 선택 후 포커스는 헤더의 그룹 select로 이동 — 선택창이 사라져 포커스를 잃지 않게. 명세에 정한 곳이 없음.
- 그룹 select의 접근 가능한 이름은 `화면 그룹`, 검색 지우기 버튼은 `검색어 지우기` — 명세에 문구가 없음.
- 그룹 변경 시 aria-live 안내 문구는 `○○ 메뉴로 바뀌었어요` — 8절은 "알린다"만 정함.
- 헤더 `병무민원` 링크에는 화살표(↗) 없이 스크린리더용 "(새 탭)"만 붙임 — ↗는 3.4에서 카드에만 정해짐.
- `비공식 도우미` 배지 모양(1px 경계, 모서리 6px, 12px 글자, --text-muted)은 직접 정함 — 5절에 값이 없어 소식 배지 크기를 따름.
- 로고 이미지 높이 32px — 5절에 값이 없음.
- 배너 제목 흰색은 `--hero-title: #FFFFFF` 변수로 둠 — 5.2 "제목은 흰색"을 변수로만 쓰기 위해. 내 정보·켜기 버튼 그림자도 `--float-shadow` 변수.
- 배너 그림 색: 문서 카드 --bg-surface, 줄·체크 원 --hero-check, 체크 표시 --brand-solid, 궤도선·점선·+ --hero-desc(옅게), 금색 점 --hero-dot — 3.3은 "연녹색/녹색/금색"만 정함.
- 저장 실패 안내는 화면 아래 가운데에 4초 표시, 배경 --text·글자 --bg-surface — 6절은 "잠깐 표시"만 정함.
- 6절 "그룹을 읽는 동안 로딩 표시"는 저장값을 다 읽은 뒤에 화면을 처음 그리는 방식으로 대신함 — 읽는 동안에는 원본이 보이고, 다른 그룹 카드가 잠깐 보이는 일이 생기지 않음.
- 검색창은 3단계에서 모양·입력·지우기·Escape·Enter 막기까지만 만들고, 실제 카드 거르기는 6단계(3.7)에서 붙임.

## 4단계
- 묶음 카드는 그리드 칸 하나에 [카드 버튼 + 바로 아래 링크 목록]을 함께 넣음 — 3.4 "카드 바로 아래에 펼쳐진다". 펼치면 그 줄 높이만 늘어남.
- 펼친 묶음 카드는 `관련 메뉴 N개 ▴`로 화살표 방향을 바꿈 — 명세는 접힌 상태(▾)만 보여 줌.
- `↗`, `▾`, `▴`, `→`는 명세에 적힌 문자를 그대로 쓰고 `aria-hidden` 처리 — 8절 "화살표는 aria-hidden".
- 묶음 카드의 하위 링크 목록 모양(흰 바탕, 1px 경계, 모서리 12px, 줄 높이 44px, 줄 사이 구분선)은 직접 정함 — 5절에 값이 없음.
- 카드 마우스 올림 시 경계선을 `--highlight-border`로 바꿈 — 5절에 마우스 올림 색이 없어서 있는 변수 중 가장 가까운 것을 씀.
- 강조 카드 아이콘의 흰색은 `--icon-solid-fg: #FFFFFF` 변수 — 5.2 "아이콘은 흰색"을 변수로만 쓰기 위해.
- 그룹 배지의 점(●)은 8px 글자로 작게 표시하고 aria-hidden — 장식이므로.
- 긴 한글 카드 이름은 `word-break: keep-all`로 단어 단위 줄바꿈 — 5열에서 글자 중간이 끊기지 않게.
- 더보기 버튼은 보이는 높이 40px(5.1)을 지키고, 투명한 확장 영역으로 누르는 높이를 44px로 맞춤 — 8절 "클릭 대상 44×44px 이상"과 함께 지키기 위해.
- 더보기 버튼에 `aria-expanded`와 `aria-controls`(카드 그리드) 추가 — 펼침 상태를 스크린리더에 알리기 위해.
- `전체 메뉴 보기 →`는 페이지 이동이 아니라 원본 버튼을 누르는 동작이므로 링크 모양의 `<button>`으로 만듦.
- 전체 메뉴를 다시 열 때 이전에 걸어 둔 `#close-nav` 대기 함수는 지우고 새로 검 — 여러 번 열고 닫아도 포커스 복귀가 한 번만 일어나게.
- 그룹 변경 시 메뉴 패널을 `key={group}`으로 다시 만들어 더보기·카드 펼침을 모두 초기화 — 3.2 "펼침 상태를 초기화".
- 선택창 뒤의 틀에 빈 패널 상자(최소 높이 320px)도 둠 — 3.1 "개선 화면 틀(카드 없이)".
- 새 탭 표시 `↗` 앞에 줄바꿈 없는 공백(U+00A0)을 둠 — 5열 좁은 카드에서 `↗`만 다음 줄로 떨어지는 것을 막기 위해(실제 사이트 확인 중 발견).

## 5단계
- 소식은 시작할 때 한 번만 읽음(원본을 숨기기 전) — 원본 목록은 페이지에 처음부터 들어 있고(2026-11-05 확인) 숨겨도 DOM에 남지만, 읽는 시점을 고정해 두는 편이 단순함.
- 제목은 `a[title]` 값을 우선 쓰고 없으면 링크 글자를 씀 — 원본의 title 속성에 잘리지 않은 전체 제목이 있음(확인함). 공백은 하나로 정리.
- 항목은 제목이 있고, 날짜가 `YYYY-MM-DD` 형식이고, 링크가 `https://www.mma.go.kr`(같은 사이트)일 때만 씀. 형식이 맞지 않는 항목은 건너뛰고 다음 항목을 씀. 쓸 수 있는 항목이 하나도 없으면 "불러오지 못했어요" 한 줄 — 3.5 "목록을 못 찾거나 비어 있으면".
- 소식 제목이 길면 말줄임 없이 줄바꿈 — 5.3의 "말줄임으로 자르지 않는다"를 소식 제목에도 적용.
- `전체 보기 →`는 목록을 여닫는 `<button aria-expanded>`, 펼친 목록의 두 링크는 같은 탭 — 3.5는 새 탭을 정하지 않았고 원본 게시판 링크도 같은 탭. Escape로 닫으면 포커스는 `전체 보기` 버튼으로 돌아감.
- 작은 화면(767px 이하)에서는 [배지+제목] 줄 아래로 [날짜 →]가 내려감 — 5절에 작은 화면 배치가 없음.

## 6단계
- 검색 함수는 `src/catalog/search.ts`에 둠 — 명세 9절 폴더에 없지만 카드 데이터만 다루는 순수 함수라 catalog 옆이 맞음. 최대 100자는 입력창 `maxLength`와 정규화 함수 양쪽에서 지킴.
- 검색 결과 수 안내(aria-live)는 입력이 0.6초 멈춘 뒤 한 번만 — 8절 "한 번만 알린다". 화면에 보이는 `메뉴 검색 결과 N개` 글자는 aria-live가 아님(중복 낭독 방지).
- 검색 결과 없음일 때의 `전체 메뉴 보기`는 안내 띠와 같은 동작(원본 전체 메뉴 열기) — 3.7.
- 검색 중에도 아래 안내 띠는 그대로 둠 — 3.7은 더보기 버튼만 숨기라고 함.
- 하위 링크 이름만 일치한 묶음 카드는 펼친 상태로 보이되 사용자가 펼친 카드도 함께 유지 — 현재 데이터에는 묶음 카드가 없어 실제로는 나타나지 않음.
