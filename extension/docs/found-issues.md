# 발견한 문제

작업하다가 그 작업의 범위 밖에서 발견해서 아직 고치지 않은 문제를 적습니다([CONTRIBUTING.md 3절](../../CONTRIBUTING.md#3-작업-범위)).

- **버그**: 원래 의도대로 동작하지 않는 것. `fix/` 브랜치로 고칩니다.
- **고칠 만한 것**: 의도대로 동작하지만 바꾸면 더 나아지는 것. `feature/` 브랜치로 고칩니다.

항목 하나를 브랜치 하나로 고치고, 고친 PR에서 그 항목을 지웁니다.

## 쓰는 형식

```markdown
### 한 줄 제목
- 발견: 날짜, 이름, 어느 작업에서 (브랜치나 PR 번호)
- 문제: 어떤 화면에서 무엇이 잘못되는지 (고칠 만한 것은 지금 어떻고 어떻게 바꾸면 좋은지)
- 위치: 관련 파일·함수 (알면)
- 고칠 방향: (알면)
```

## 버그

### 로그아웃 뒤 병무민원 새 화면 위쪽에 로그인 버튼이 보이지 않음
- 발견: 2026-11-26, 김도형, 내 정보 작업(PR #12)
- 문제: 로그아웃 상태에서 원본 위쪽 링크(`#util_layout2`)의 글자는 `로그인`이 아니라 `접속하기`다. 새 화면은 `로그인` 글자만 찾아서 로그인 버튼을 그리지 않는다.
- 위치: `extension/src/portal/portalDom.ts`의 `utilElements()` (`login` 찾는 줄)
- 고칠 방향: `접속하기`도 로그인 링크로 본다. 내 정보는 같은 판단을 `src/my-info/portalLogin.ts`에서 따로 하고 있어서, 고친 뒤 이 판단을 한 곳으로 합칠 수 있다.

### 병무청 첫 화면에 안내 페이지가 뜨면 새 화면이 나오지 않음
- 발견: 2026-11-26, 김도형, 내 정보 작업(PR #12)
- 문제: 병무청 첫 화면(`www.mma.go.kr/`) 자리에 본인선택원 신청 안내 페이지가 떠 있을 때, 원래 첫 화면 요소를 찾지 못해 콘솔에 `[bmgj] DOM not found`가 나오고 새 화면이 적용되지 않는다.
- 위치: `extension/src/content/main.tsx`의 `findOriginalDom()` 호출, `extension/src/content/mount.ts`의 `findOriginalDom()`
- 고칠 방향: (아직 정하지 않음) 안내 페이지가 뜨는 경우에 화면을 어떻게 보여 줄지 먼저 정해야 한다.

- 발견: 2026-11-26, 이재혁, A-M01·A-M04·A-M05 작업(`feature/a-m01-m05`). 내 정보 작업(PR #12)에서도 다시 나옴.
