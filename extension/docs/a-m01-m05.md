# A-M01·A-M04·A-M05 공통 테마

## 적용 범위

최상위 `www.mma.go.kr/contents.do`의 다음 세 주소만 허용한다. `mc`가 여러 번 있거나 다른 경로·도메인·프레임이면 적용하지 않는다. 유입 경로와 공통 메뉴 DOM을 근거로 적용 범위를 넓히지 않는다.

| 카드 | mc | 화면 |
| --- | --- | --- |
| A-M01 | mma0003746 | 안내 및 신청(지원) |
| A-M04 | mma0000743 | 이달의 모집계획 |
| A-M05 | mma0000386 | 안내 및 지원절차의 육군 모집안내 진입 화면 |

A-M06~A-M10과 병무민원 도메인은 제외한다. 군별·분야별 탭의 다른 `mc` 주소도 이번 허용 목록에 포함하지 않는다. 해당 화면에서는 기존 `main` 처리가 그대로 실행된다.

## 코드 구성과 연결

새 코드는 `extension/src/a-m01-m05/`에 둔다.

- `index.tsx`: 독립 Shadow DOM과 React 루트, 초기화, 오류 경계, 실패 시 원본 복원 및 기존 처리로 복귀.
- `menuTheme.ts`: 세 도착 주소 허용 목록과 기능 전용 식별자.
- `pageEnhancements.ts`: 원본 DOM을 유지하면서 기능 전용 루트 속성·클래스만 적용하고 해제 시 이전 값 복원. 링크나 제목을 변경하지 않는다.
- `MenuThemeWidget.tsx`: 기존 내 정보 위젯 재사용, 화면 모드 전환·구독, 설정 저장 실패 안내. CSS는 `?inline`으로 읽어 `<style>`로 렌더링한다. 본문용 스타일은 React portal로 문서 head에 넣는다.
- `menuTheme.css`: 본문·표·탭·버튼·하단 만족도 조사 스타일.
- `widget.css`: 기능 전용 전환 버튼과 상태 안내 스타일.

기존 파일 변경은 `extension/src/content/main.tsx`에 추가한 **2줄**뿐이다.

1. `startAM01M05` import.
2. `start()` 첫 줄에서 호출하고 담당 화면을 처리했으면 반환.

원래 화면 전환과 오류 복원은 기능 폴더에서 처리한다. 기존 오류 처리·데이터 검증·메인·병무민원 렌더링 코드는 수정하지 않는다.

## 화면과 원본 보존

- 백업의 세 대상 화면과 같은 초록·민트 테마, 양쪽 탐색 메뉴 숨김, 본문 확장, 제목 띠 너비, 버튼 크기, 본문 여백, 탭 중앙 정렬, 만족도 조사 배치를 유지한다.
- 원본 제목·폼·표·링크·이벤트·요소 순서를 보존한다. 전환 과정에서도 입력값을 지우거나 본문을 다시 만들지 않는다.
- `data-bmgj-a-m01-m05-theme`가 있는 동안에만 본문 CSS를 적용한다. 새 클래스·속성·CSS 변수는 기능 이름을 포함해 다른 담당자와 충돌하지 않게 한다. 원본 요소의 기존 클래스 이름은 유지한다.
- 공통 내 정보 위젯과 그 기존 스타일은 import해 재사용하며, `src/ui/styles.css`에는 추가하지 않는다.
- 기존 `bmgj.prefs.viewMode`를 사용한다. 원래 화면 전환 시 루트 표식을 복원하고, 초기화 또는 렌더링 오류 시에도 기능 폴더 안에서 원본 표시로 되돌린다.

## 확인 방법

`extension`에서 `npm run build`를 실행한다. 생성되는 `dist`는 검증용이며 PR에 포함하지 않는다.

Chrome에서 세 대상 주소의 테마와 원래 화면 전환, 본문 상태와 링크 속성 보존을 확인한다. A-M06~A-M10, 다른 군·하위 주소, 병무청 메인과 병무민원 첫 화면은 이번 기능의 스타일이 적용되지 않아야 한다. 저장 실패·초기화 실패·렌더링 실패에서도 원본 화면을 유지하는지 확인한다.

검증은 공개 HTML과 원본 CSS를 재현한 Chrome에서 수행한다. 실제 인증 이후의 신청서 작성이나 서버 제출은 포함하지 않는다.

확인 결과: `npm run build` 통과. 공개 화면 12종에서 허용 목록 3종만 적용되고 A-M06~A-M10 및 다른 군·하위 주소는 제외됨을 확인했다. 대상 화면은 1440px·390px에서 백업 빌드와 본문 위치·너비·높이·여백·색상을 비교했다. 원본 DOM·링크 target·입력값 보존, 원래 화면 복원, 병무청·병무민원 첫 화면의 기존 카드·링크·프레임 표시 유지, 경로·중복 mc 차단, 초기화·렌더링·설정 저장 실패 처리를 확인했다.

## 디자인 통일 (2026-11-26, 오동규)

팀 결정으로 A-M01~A-M10 하위 페이지가 같은 모양(확장 헤더 + 카드 배너 + 전체 너비 본문)을 쓰게 되면서 이 기능의 구조가 바뀌었다. 자세한 내용은 `design-unify.md`.

- 독립 시작 코드(`index.tsx`, `MenuThemeWidget.tsx`, `pageEnhancements.ts`, `widget.css`)를 없앴다. 대신 `register.ts`가 세 페이지를 병무청 하위 페이지 공통 틀(`src/subpage`)에 등록한다. 헤더·카드 배너·원래 화면 전환(헤더의 `원래 화면 보기`)·오류 복원은 공통 틀이 한다.
- `content/main.tsx`에서는 `startAM01M05()` 대신 `registerAM01M05()`를 부른다.
- `menuTheme.css`에는 이 페이지들에만 필요한 규칙(안내 및 신청 2열 배치·파란 제목 상자·버튼 크기, 안내 상자 색)만 남겼다.
  - 탭 모양과 만족도 조사 배치 규칙은 모든 하위 페이지에 쓰도록 `src/subpage/content.css`로 옮겼다.
  - 레이아웃·제목·표·버튼·링크 규칙은 공통 본문 다듬기와 겹쳐서 뺐다.
- 페이지 표식(`data-bmgj-a-m01-m05-theme`)은 공통 틀이 새 화면일 때만 붙인다. 원래 화면으로 돌아가면 뗀다.
