# p-a-left: 병무민원 세부 화면 공통 틀 + 입영 준비 카드 6개 (김도형)

병무민원 첫 화면 카드를 눌러 들어간 화면을 첫 화면과 같은 디자인으로 보여 준다.
공통 틀(`src/portal/page/`)은 문준석 등 다른 사람도 자기 카드를 등록해 쓰는 바탕이다.

## 폴더

| 폴더 | 내용 |
| --- | --- |
| `src/portal/page/` | 공통 틀. 카드 등록부, 바깥 틀(헤더·화면 머리), 프레임 본문 꾸밈, 글 배치 |
| `src/portal/p-a-left/` | 내 카드 6개 등록, 다음연도 접수 일정의 관할 지방청 표시 |

폴더 밖에서 고친 파일(연결만):

- `src/content/main.tsx` +2줄: `registerPALeft` 가져오기와 `startPortal()` 첫 줄에서 호출.
- `src/portal/PortalApp.tsx` +8줄 −2줄: "첫 화면이 아니면 `PortalPageShell`을 그린다" 한 곳(가져오기 1줄 포함).

## 다른 사람이 카드를 등록하는 방법

```ts
// 예: src/portal/<내 범위>/register.ts
import { getPortalCard } from '../../catalog/portalCards';
import { registerPortalPages } from '../page/registry';
import css from './<내 범위>.css?inline';          // 선택: 그 화면에만 넣을 프레임 CSS
import { enhance } from './enhance';               // 선택: 그 화면에만 할 일

export function registerMine(): void {
  registerPortalPages([
    { card: getPortalCard('P-A-M03') },
    { card: getPortalCard('P-A-M07'), frameCss: css, enhance },
  ]);
}
```

그리고 `src/content/main.tsx`의 `startPortal()` 안에서 `registerMine()`를 한 줄 호출한다.

- 메뉴 번호는 카드 링크 주소의 `menuNo`(예: `index_mwps.jsp?menuNo=22017`)에서 읽는다. `portalCards.ts`는 고치지 않는다.
- 링크가 2개 이상인 카드(예: 신청·변경·취소)는 링크마다 같은 카드로 등록되고, 화면 머리에 그 링크들이 탭으로 나온다.
- 같은 메뉴 번호를 두 번 등록하면 먼저 등록한 것을 쓰고 콘솔에 알린다.
- `frameCss`의 선택자는 `html.bmgj-page-frame` 아래로, 표시용 속성 이름은 `data-bmgj-<내 범위>-…`로 쓴다.
- `enhance(doc)`는 공통 글 배치가 끝난 뒤 프레임 문서를 받아 실행된다. 원본 글을 지우거나 옮기지 않는다. 오류가 나면 공통 틀이 꾸밈을 모두 빼고 원본 화면으로 둔다.

## 동작

- 어느 화면인지는 프레임 왼쪽 메뉴에서 선택된 항목(`#leftMenu li.on`)의 menuNo로 안다. 화면 주소는 여러 메뉴가 같은 주소(`moveHwaMyeon_ID.do`)를 써서 쓸 수 없다(2026-11-23 확인). 그래서 대상 메뉴 안에서 다음 단계로 넘어가도 왼쪽 메뉴가 같으면 계속 개선 화면.
- 신청·변경·취소는 원본 프레임 화면의 입력값·스크립트·인증 흐름을 그대로 써야 하므로 다시 만들지 않고 모양만 바꾼다. 바깥 틀이 같은 출처 프레임 문서에 `<style id="bmgj-page-frame-style">`와 `<html class="bmgj-page-frame">`만 넣고 뺀다. 원래 화면으로 돌리면 둘 다 지우고 원본 방식(+100px)으로 프레임 높이를 다시 맞춘다.
- 바깥 틀: 첫 화면과 같은 전자정부 띠·헤더 아래에 `민원 첫 화면` 링크와 화면 머리(카드와 같은 아이콘·이름·설명). 바깥 틀 CSS는 `page.css`를 `PortalPageShell`이 `<style>`로 넣는다(`styles.css`는 고치지 않음).
- 프레임 안: 원본 머리(전자정부 띠·로고·대메뉴)·위치·왼쪽 메뉴·제목·푸터를 숨기고, 본문을 흰 둥근 패널(바깥 헤더와 같은 폭)에 병무민원 색으로 다시 그린다. 로그인 남은 시간(`#counter`)·연장·나가기는 바깥 헤더가 계속 읽도록 DOM에 남긴다. 자동 로그아웃 예고창(`#popup`)은 숨기지 않는다.
- 프레임 높이: 원본 `frameReLoad()`와 같은 방식(height 0 → body.scrollHeight, +2px)으로 맞추고, 원본 스크립트가 내용을 펼치면 `#sub_layout` 크기 변화를 보고 다시 맞춘다.
- 원래 화면 모드에서는 등록된 화면에도 `병무길잡이 켜기` 버튼을 띄운다. 첫 방문 그룹 선택창은 첫 화면에서만.
- 그룹·화면 모드는 `PortalApp`의 상태와 저장 함수를 그대로 받아 쓴다(첫 화면과 같은 저장값).

## 글 배치 (사용자 요청 2026-11-23: "가독성 좋게, 빠뜨리는 내용 없이")

원본 글은 지우거나 순서를 바꾸지 않는다. `page/layout.ts`가 모양용 표시(`data-bmgj-page`)만 달고, 글자를 감싸는 곳은 "항목명 : 값"의 항목명과 "첫째, 둘째…"의 순서말뿐(글자는 그대로).

- 항목명 꼬리표: 맨 위 목록은 그 줄만, 하위 목록은 모든 줄이 같은 꼴일 때만(들쭉날쭉 방지).
- 짧은 제목 + 하위 목록 = 묶음 상자. (사용자 결정) 좌우로 나란히 놓지 않고 위아래로만 쌓는다.
- 전화번호 목록 = 기관·번호 표.
- 제목이 하나뿐인 유의사항·기타사항 구역 = 노란 안내 상자.
- 바로가기·내려받기 링크 = 꼬리표, 입력칸 있는 표 강조, "첫째, 둘째…" = 순서 꼬리표, 버튼만 있는 항목은 글머리표 없음.
- 원본 빨강·파랑 강조는 개선 화면 색(대비 4.5:1 이상), 한 줄 최대 880px.
- (사용자 결정) 제출 문구와 `예` 버튼 주변에 바탕색을 넣지 않음 — 위에 구분선만 두고 가운데 정렬.
- 상자 안에 목록 없이 놓인 li·p도 같은 글머리표·크기로, 표 하나만 든 상자는 테두리 없이, 동의 체크칸은 강조 칸으로, 목록·표 다음 소제목은 위 32px.
- 프레임 문서의 요소는 콘텐츠 스크립트에서 다른 실행 환경 객체라 `instanceof HTMLElement`가 항상 거짓 → `nodeType`으로 판별.
