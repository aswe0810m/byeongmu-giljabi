# 하위 페이지 새 화면 — A 그룹 카드 A-M06~A-M10

입영 준비·복무 중(A) 그룹 메인 화면 둘째 줄 카드 5개가 이동하는 병무청 페이지의 화면을 바꾼다.
분업 중 충돌을 줄이려고 이 기능의 구현 결정은 공용 `implementation-decisions.md` 대신 이 파일에 적는다.

## 대상 (2026-11-24 확인)

| 카드 | 주소 | 화면 |
|---|---|---|
| A-M06 모집 공지사항 | `/board/boardList.do?gesipan_id=69` 외 군별 게시판 4개 | 공통 틀 + **합친 공지 목록** |
| A-M07 병역판정검사 | `/contents.do?mc=usr0000167` | 공통 틀 + 본문 다듬기 |
| A-M08 입영판정검사 | `/contents.do?mc=mma0002909` | 공통 틀 + 본문 다듬기 |
| A-M09 재학생 입영연기 | `/contents.do?mc=usr0000174` | 공통 틀 + 본문 다듬기 |
| A-M10 현역병 선발취소 및 입영일자 연기신청 | `/contents.do?mc=usr0000295` | 공통 틀 + 본문 다듬기 |

- 게시판은 육군(69)·해군(70)·해병대(72)·공군(71)·취업맞춤특기병(267) 5개 모두에 같은 화면을 적용한다.
  - 첫 화면이면 합친 목록을 보여 준다.
  - 검색 결과나 2쪽 이후(POST)는 원본 목록을 공통 틀 안에서 다듬어 보여 준다.
  - 글 보기(`boardView.do`)는 공통 틀 + 본문 다듬기.
- 왼쪽 메뉴로 이동한 다른 페이지는 바꾸지 않는다(기존처럼 내 정보 버튼만).
- 다른 카드의 페이지를 추가하려면 `src/subpage/pages.ts`의 목록에 주소를 넣으면 같은 공통 틀이 적용된다.

## 구조

- `src/subpage/start.tsx`: 시작점. `content/main.tsx`가 메인이 아닌 페이지에서 먼저 부르고, 맡은 페이지가 아니면 false를 돌려준다.
- 원본 DOM은 옮기지 않는다. 확장 화면은 Shadow DOM 호스트 4곳에 그린다.
  - 맨 위(`#bmgj-root`): 헤더·경로·제목
  - 원본 `#side` 자리: 왼쪽 메뉴
  - 원본 `#contents` 앞: 합친 공지 목록
  - `#secrion` 뒤: 푸터
- React 루트는 하나이고, 나머지 호스트에는 portal로 그린다.
- 숨기는 것: 원본 헤더 안쪽, 경로(`#path`), 왼쪽 메뉴(`#side`), 제목(`#sub_head`), 주요누리집 상자(`#container_box3`), 푸터.
  - 게시판 탭(`.tab_common`)은 합친 목록과 글 보기에서만 숨긴다.
  - 원래 `style` 속성을 기록해 두었다가 그대로 되돌린다(메인과 같은 방식).
- 본문(`#contents`)은 원본 그대로다. 링크·버튼·스크립트·만족도 조사가 원래대로 동작한다.
  - 문서에 넣은 `content.css`로 모양만 바꾼다. 모든 규칙이 `html.bmgj-sub` 아래에 있어 원래 화면으로 돌아가면 영향이 없다.
  - 원본 CSS가 h3/h4 여백 등에 `!important`를 써서 그 자리만 `!important`.
- 원래 화면 보기 / 병무길잡이 켜기 / 그룹은 메인과 같은 저장값(`bmgj.prefs`)을 쓴다. 첫 방문 그룹 선택창은 하위 페이지에서 띄우지 않는다.

## 결정 사항

- (사용자 결정) 본문은 방식 (가) "모양만 다듬기"로 시작하고, 효과가 큰 페이지만 나중에 맞춤 화면 (나)를 얹는다.
- (사용자 결정) 모집 공지사항 정리를 이번에 함: 군별 게시판 5개를 한 목록으로 합치고, 잘린 제목 복원·같은 글 한 번만·분야 필터·접수 D-Day.
- (사용자 결정) 잘린 제목과 D-Day를 위해 확장이 게시판 목록·글 보기 페이지를 읽는다.
  - 공개 페이지 GET만, `credentials: 'omit'`, 한 번에 2개씩.
  - 게시판 목록 5개는 30분 동안 저장값을 쓴다(`bmgj.noticeLists.v1`, 하나라도 실패하면 저장하지 않음).
  - 글 보기는 글 번호별로 저장하고(`bmgj.noticeDetails.v1`, 최대 400개) 목록 제목과 맞지 않을 때만 다시 읽는다. 최근 45일 모집 안내 글은 하루마다 다시 읽는다. 한 번 방문에 최대 30개.
- 목록은 게시판마다 최근 20개(`pageUnit=20`, 원본 `건씩 보기` 선택지 안의 값). 화면에는 20개씩, `더보기`로 20개 더.
- 같은 글 판단은 게시판 ID + 글 번호(`gsgeul_no`). 원본 목록 위쪽의 고정 공지가 아래 일반 목록에 다시 나오는 것을 한 번만 보여 준다.
- 원본의 고정(`공지`) 표시는 최근 글 대부분에 붙어 있어 구분이 되지 않으므로 배지로 보여 주지 않는다. 정렬은 작성일 최신순.
- 처음 군 필터: 육군 게시판(카드가 여는 곳)으로 들어오면 `전체`, 다른 군 게시판으로 들어오면 그 군.
- 분야 필터는 제목 낱말로 나눈다(`notice/fields.ts`). 지금 고른 군에 글이 있는 분야만 보여 준다.
- 접수 상태는 글 본문의 `접수기간 : 날짜 ~ 날짜`에서 읽는다(끝 시각이 없으면 그날 23:59).
  - 시작 전: `접수 D-n`
  - 접수 중: `마감 D-n` / `오늘 마감`
  - 끝난 뒤: `접수 마감`
  - 날짜 계산은 `profile/profile.ts`의 `countdown`(한국 날짜 기준)을 그대로 쓴다.
- 이전 글 검색은 `○○ 게시판 원래 목록 보기` 버튼으로 원본 목록(검색 양식·쪽 이동·군별 탭)을 펼쳐서 한다. `모집 공지사항 새 목록 보기`로 돌아온다.
- 왼쪽 메뉴의 지금 페이지는 원본이 표시한 `li_on`을 따른다. 군지원 안내 메뉴는 원본 HTML의 태그 짝이 맞지 않아 같은 주소의 항목(`모집병 지원 안내`)이 겹치므로, 주소 비교는 `li_on`이 없을 때만 쓴다.
- 1,023px 이하에서는 왼쪽 메뉴가 본문 위로 올라가고 `○○ 메뉴 펼치기` 버튼으로 접힌다.
- A-M10 페이지 본문은 클릭 영역이 있는 이미지 지도(`usemap`)라서 이미지를 늘리지 않는다. 늘리면 클릭 위치가 어긋난다. 맞춤 화면 (나)의 후보.
- 원본 본문의 양쪽 맞춤(justify)은 한글 사이를 크게 벌리므로 왼쪽 맞춤으로 바꿨다(표 칸 정렬은 그대로).
