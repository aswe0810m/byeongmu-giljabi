# 병무길잡이 (byeongmu-giljabi)

> 병무청 사이트, 더 쉽게.
> 병무청 웹사이트의 화면을 보기 좋게 바꿔 주는 **크롬 확장 프로그램**입니다.

본 프로젝트는 병무청과 관련 없는 **비공식 학생 프로젝트**입니다.
(숭실대학교 오픈소스기반기초설계 5조)

## 프로젝트 소개

병무청 웹사이트는 병역 의무자라면 누구나 한 번은 써야 하는 공공 서비스지만,
메뉴가 너무 많고 정보가 흩어져 있어 원하는 정보를 찾기 어렵습니다.

병무길잡이는 새로운 사이트를 만드는 대신, **이미 쓰고 있는 병무청 사이트 자체를
보기 좋게 바꾸는** 방식으로 이 문제를 해결합니다.
주소와 내용은 그대로이고, 화면 구성만 쓰기 편하게 바뀝니다.

## 해결하려는 문제

| 문제 | 현재 병무청 사이트 |
|---|---|
| 메뉴가 너무 많음 | 전체 메뉴 링크 196개, 자주 쓰는 메뉴를 찾기 어려움 |
| 정보가 흩어짐 | 군별 게시판 5개로 나뉜 공지, 특기별 필터 없음, 잘린 제목과 중복 공지 |
| 반복 입력 | 점수 확인 시 신체조건 11개·가산항목 19개를 방문할 때마다 다시 입력 |

## 주요 기능 (MVP)

- **메뉴 재구성 & 공통 디자인**
  자주 쓰는 메뉴(모집병 지원, 입영일자 본인선택, 입영 연기 등)를 목적별로 앞에 배치하고,
  가끔 쓰는 메뉴는 접어 둡니다. 페이지마다 다른 디자인을 통일합니다.
- **공지사항 화면 정리**
  표를 읽기 쉬운 목록으로 바꾸고, 잘린 제목 복원·중복 공지 제거·분야별 필터·마감 D-day를 제공합니다.
- **점수 확인 자동 입력**
  자격증, 신체조건, 가산항목을 한 번 입력하면 저장해 두고 다음 방문 때 자동으로 채웁니다.

### 추가 목표
- 로그인 없이 예상 점수 계산
- 저장된 프로필 기반 지원 가능 특기 추천

## 설계 원칙

- 로그인과 지원서 제출은 **대신하지 않습니다.** 사용자가 공식 화면에서 직접 진행합니다.
- 입력한 정보는 **사용자 컴퓨터(확장 저장소)에만** 저장하며 외부로 전송하지 않습니다.
- 병무청 서버에는 **원래와 같은 요청만** 보냅니다. 보이는 화면만 바꿉니다.
- 병무청 로고를 사용하지 않으며, 공식 서비스처럼 보이게 만들지 않습니다.

## 🛠 기술 스택 (예정)

- Chrome Extension (Manifest V3)
- JavaScript / TypeScript
- Content Script (병무청 페이지 화면 변경), Chrome Storage API

## 🚀 설치 방법 (개발 버전)

1. 이 저장소를 내려받습니다.
2. 크롬 주소창에 `chrome://extensions` 입력
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램 로드** → 확장 폴더 선택
