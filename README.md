# 병무길잡이 (byeongmu-giljabi)

> 병무청 사이트, 더 쉽게.
> 병무청 웹사이트의 화면을 보기 좋게 바꿔 주는 **크롬 확장 프로그램**입니다.

본 프로젝트는 병무청과 관련 없는 **비공식 학생 프로젝트**입니다.
(숭실대학교 오픈소스기반기초설계 5조)

## 프로젝트 소개

병무청 웹사이트는 병역 의무자라면 누구나 한 번은 써야 하는 공공 서비스지만,
메뉴가 너무 많고 정보가 흩어져 있어 원하는 정보를 찾기 어렵습니다.

병무길잡이는 새로운 사이트를 만드는 대신, **이미 쓰고 있는 병무청 사이트 자체를
보기 좋게 바꾸는** 방식으로 이 문제를 해결합니다.
주소와 내용은 그대로이고, 화면 구성만 쓰기 편하게 바뀝니다.

## 해결하려는 문제

| 문제 | 현재 병무청 사이트 |
|---|---|
| 메뉴가 너무 많음 | 전체 메뉴 링크 196개, 자주 쓰는 메뉴를 찾기 어려움 |
| 정보가 흩어짐 | 군별 게시판 5개로 나뉜 공지, 특기별 필터 없음, 잘린 제목과 중복 공지 |
| 반복 입력 | 점수 확인 시 신체조건 11개·가산항목 19개를 방문할 때마다 다시 입력 |

## 주요 기능 (MVP)

- **메뉴 재구성 & 공통 디자인**
  자주 쓰는 메뉴(모집병 지원, 입영일자 본인선택, 입영 연기 등)를 목적별로 앞에 배치하고,
  가끔 쓰는 메뉴는 접어 둡니다. 페이지마다 다른 디자인을 통일합니다.
- **공지사항 화면 정리**
  표를 읽기 쉬운 목록으로 바꾸고, 잘린 제목 복원·중복 공지 제거·분야별 필터·마감 D-day를 제공합니다.
- **점수 확인 자동 입력**
  자격증, 신체조건, 가산항목을 한 번 입력하면 저장해 두고 다음 방문 때 자동으로 채웁니다.

### 추가 목표
- 로그인 없이 예상 점수 계산
- 저장된 프로필 기반 지원 가능 특기 추천

## 설계 원칙

- 로그인과 지원서 제출은 **대신하지 않습니다.** 사용자가 공식 화면에서 직접 진행합니다.
- 입력한 정보는 **사용자 컴퓨터(확장 저장소)에만** 저장하며 외부로 전송하지 않습니다.
- 병무청 서버에는 **원래와 같은 요청만** 보냅니다. 보이는 화면만 바꿉니다.
- 병무청 로고를 사용하지 않으며, 공식 서비스처럼 보이게 만들지 않습니다.

## 🛠 기술 스택

- Chrome Extension (Manifest V3)
- TypeScript, React, Vite
- Content Script (병무청 페이지 화면 변경), Chrome Storage API

## 다운로드

저장소의 [**Releases**](https://github.com/aswe0810m/byeongmu-giljabi/releases) 페이지에서 최신 버전의
`byeongmu-giljabi-v0.x.x.zip`을 내려받고 압축을 풉니다.

> 저장소 페이지의 **Code → Download ZIP**에는 설치 파일(`dist`)이 들어 있지 않습니다.
> 소스만 들어 있으므로 반드시 **Releases**에서 받아 주세요.

## 설치 방법 (크롬)

1. 크롬 주소창에 `chrome://extensions` 를 입력합니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다** 버튼을 누릅니다.
4. 압축을 푼 **`byeongmu-giljabi-v0.x.x`** 폴더를 선택합니다.
   (폴더 안에 `manifest.json`이 바로 보이는 폴더입니다.)
5. 확장 프로그램 목록에 **병무길잡이**가 보이면 설치가 끝난 것입니다.

> 설치한 뒤 이미 열려 있던 병무청 탭은 **새로고침**해야 바뀐 화면이 나타납니다.

## 사용 방법

### 병무청 메인 화면 (www.mma.go.kr)

1. [병무청 누리집](https://www.mma.go.kr)에 들어가면 메인 화면이 병무길잡이 화면으로 바뀝니다.
2. 처음 방문하면 **"지금 어떤 상황인가요?"** 창이 뜹니다. 자신의 상황을 고릅니다.
   - **입영 준비·복무 중**: 모집병 지원, 병역판정검사, 입영 연기 등
   - **전역·예비군**: 병적증명서 발급, 동원훈련 안내 등
3. 고른 상황에 맞는 **자주 쓰는 메뉴 카드**가 보입니다. 카드를 누르면 해당 병무청 페이지로 이동합니다.
   - **더보기**: 가끔 쓰는 메뉴 카드를 더 펼칩니다.
   - **전체 메뉴 보기 / 헤더 검색창**: 병무청 전체 메뉴를 한 창에서 보고 이름으로 검색할 수 있습니다.
   - **소식**: 병무청 공지사항의 최근 글을 잘리지 않은 제목으로 보여 줍니다.
4. 상황(그룹)은 헤더의 **화면 그룹** 선택칸에서 언제든 바꿀 수 있습니다.

### 병무민원 화면 (mwpt.mma.go.kr)

- 헤더의 **병무민원**을 누르면 병무민원포털 첫 화면도 같은 디자인(남색 계열)으로 바뀝니다.
- 신청·조회 같은 민원 메뉴가 카드로 정리되어 있고, 나머지는 **전체 메뉴 보기**에서 찾을 수 있습니다.
- 로그인한 상태라면 헤더에 **로그인 남은 시간**과 연장·나가기 버튼이 함께 보입니다.
- 민원 메뉴를 누른 뒤의 화면(신청서 작성 등)은 원래 병무민원 화면 그대로 진행합니다.

### 내 정보

화면 **오른쪽 가장자리**에 마우스를 올리거나 **내 정보** 버튼을 누르면 내 정보 창이 열립니다.

- **지원 희망 분야**: 지원하고 싶은 분야(예: 어학병)를 저장하면, 병무청 공식 모집 일정을 읽어 **접수 마감까지 남은 날짜(D-Day)**를 보여 줍니다.
- **인적사항**: 성명, 생년월일, 연락처 등을 직접 입력해 저장할 수 있습니다.
  병무민원에서 본인인증 후 통합지원서 화면에 들어가면, 화면에 보이는 인적사항이 자동으로 반영됩니다.
- **화면 설정**: 화면 그룹 변경, 원래 화면으로 전환, 설정 초기화를 할 수 있습니다.

입력한 정보는 **이 브라우저(확장 저장소)에만** 저장되고 외부로 보내지 않습니다.
비밀번호, 인증번호, 주민등록번호는 읽거나 저장하지 않습니다.

### 원래 병무청 화면으로 돌아가기

- 헤더의 **원래 화면 보기**를 누르면 원래 병무청 화면으로 돌아갑니다.
- 다시 바꾸려면 화면에 보이는 **병무길잡이 켜기** 버튼을 누릅니다.
- 확장 프로그램을 완전히 끄려면 `chrome://extensions`에서 병무길잡이의 스위치를 끕니다.

## 새 버전으로 업데이트

1. [Releases](https://github.com/aswe0810m/byeongmu-giljabi/releases)에서 새 버전 zip을 받아 압축을 풉니다.
2. `chrome://extensions`에서 예전 병무길잡이를 **삭제**하고, 새 폴더를 [설치 방법](#설치-방법-크롬)대로 로드합니다.
   (또는 예전에 로드한 폴더의 내용을 새 파일로 바꾼 뒤 병무길잡이 카드의 **새로고침(↻)**을 누릅니다.)
3. 열려 있던 병무청 탭을 새로고침합니다.

> 화면 그룹·내 정보 등 저장한 값은 확장을 삭제하면 지워집니다. 유지하려면 폴더 내용을 바꾸고 새로고침하는 방법을 쓰세요.
